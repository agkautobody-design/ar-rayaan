Art slots for the learning games. Each game draws its board or card art from
a file here when it exists, and from code (the same theme) when it does not.
Do not add other kinds of file. The file names are listed in
lib/features/games/ui/learning_widgets.dart (kGameArtSlots) and in
docs/content_needed/GAMES_CONTENT_NEEDED.md (section "Art to export").
